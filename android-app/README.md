# 1.5 Adana Telemetri - Android Uygulaması

Bu proje, telemetri dashboard'unu Android uygulaması olarak çalıştırır.

## Gereksinimler

- Android Studio (Arctic Fox veya üzeri)
- Android SDK 34

## Kurulum

1. Android Studio'yu açın
2. "Open" seçin ve `android-app` klasörünü gösterin
3. Gradle sync tamamlanmasını bekleyin
4. Run (▶️) butonuna basın

## APK Oluşturma

1. Android Studio'da: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. APK dosyası: `app/build/outputs/apk/debug/app-debug.apk`

## Özellikler

- WebView ile tam ekran dashboard görünümü
- Mavi yükleme çubuğu
- Geri tuşu desteği
- Dark mode tema
- JavaScript ve LocalStorage desteği
